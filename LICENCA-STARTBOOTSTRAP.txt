Moldes do Nepenthes (pasta moldes/): modelos gratuitos do GitHub, com licença MIT,
convertidos para a linguagem Nepenthes. O HTML foi reescrito em português e ligado ao
banco do site; o CSS e as imagens vêm dos projetos abaixo (imagens reduzidas, fontes
trocadas por fontes locais, sem CDN).

  blog      Start Bootstrap Clean Blog      https://github.com/StartBootstrap/startbootstrap-clean-blog
  portal    Start Bootstrap Modern Business https://github.com/StartBootstrap/startbootstrap-modern-business
  wiki      Start Bootstrap Simple Sidebar  https://github.com/StartBootstrap/startbootstrap-simple-sidebar
  estatico  Start Bootstrap Landing Page    https://github.com/StartBootstrap/startbootstrap-landing-page
  imagens   também do Start Bootstrap Agency https://github.com/StartBootstrap/startbootstrap-agency
  Bootstrap 5.2.3 (CSS dentro dos temas e bootstrap.bundle.min.js) https://github.com/twbs/bootstrap
  Bootstrap Icons 1.11.3 (ícones SVG em moldes/icones)              https://github.com/twbs/icons
