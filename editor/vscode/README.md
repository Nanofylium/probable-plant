# Nepenthes para VS Code

Cores da sintaxe e atalhos para programas `.nep` e sites `.nep.html`: código dentro de `<nep>` e `<api>`, valores em `{{ }}`, expressões em `test=` e `in=`, textos com crases `` `Olá, {nome}` ``.

Atalhos (digite e aperte Tab): `page`, `nep`, `each`, `if`, `form`, `live`, `api`, `{{` nos sites; `fn`, `if`, `for`, `try`, `tx` nos programas.

## Instalar

Baixe `nepenthes-0.2.0.vsix` (gerado pela CI do repositório, aba Actions) e, no VS Code: Extensões > menu `...` > **Instalar do VSIX...**.

Ou, para testar sem empacotar, copie esta pasta para `~/.vscode/extensions/nepenthes` e reinicie o VS Code.
