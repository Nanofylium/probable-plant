Este arquivo é o código do site, como um arquivo .php: quem monta as páginas, guarda os dados e manda os e-mails é o programa nep. Aberto direto, ele não mostra o site.

  1. Ver como ficou: abra a prévia (site-previa.html). Para criar ou atualizar a prévia: nep previa site.nep.html
  2. No computador: nep dev site.nep.html e abra http://localhost:8000
  3. No ar: envie para a hospedagem com o nep.cgi e o .htaccess.
